# 営業メール・フォーム送信ツール

Google スプレッドシート（Mobirio_アタックリスト）の会社リストをもとに、次の2つを行うツールです。

- **メール**：Mac の「メール」アプリから自動で送信します（1日の上限まで、間隔をあけて送信）
- **お問い合わせフォーム**：ブラウザでフォームを開いて自動入力します。**送信ボタンは自分で押します**（半自動）

送った結果はスプレッドシートに記録されるので、同じ会社に二重に送ることはありません。

> ⚠ このフォルダはホームページ用ではありません。ホームページをサーバーにアップロードするときは、
> `sales-mailer` フォルダはアップロードしないでください。

---

## 1. 最初に1回だけやる準備

### 1-1. Python と必要な部品を入れる

Mac の「ターミナル」を開いて、このフォルダに移動します（フォルダをターミナルにドラッグすると場所が入力できます）。

```bash
cd ~/Desktop/-HP/sales-mailer
```

```bash
python3 -m venv .venv
```

```bash
source .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

`python3` が見つからないと表示されたら、画面の案内に従って「コマンドライン・デベロッパ・ツール」をインストールしてから、もう一度実行してください。

フォームの自動入力には Google Chrome を使います（インストールされていない場合は入れてください）。
Chrome を使わない場合は、`config.toml` の `browser_channel` を `""` にして、次を実行します。

```bash
python3 -m playwright install chromium
```

### 1-2. Google スプレッドシートとの接続

ツールが**自分の Google アカウントで**スプレッドシートを読み書きできるようにします。

1. https://console.cloud.google.com/ を開き、上部のプロジェクト選択から **新しいプロジェクト** を作る（名前は自由、例: sales-mailer）
2. 上部の検索欄で「Google Sheets API」を開き、**有効にする**
3. 検索欄で「OAuth 同意画面」（または「Google Auth Platform」）を開き、「開始」を押して次のように入力して作成する
   - アプリ名：sales-mailer など自由／ユーザーサポートメール：自分のアドレス
   - 対象（ユーザーの種類）：**内部**
   - 連絡先メールアドレス：自分のアドレス
4. 「クライアント」（または「認証情報」→「認証情報を作成」→「OAuth クライアント ID」）を開き、
   アプリケーションの種類に **デスクトップ アプリ** を選んで作成する
5. 作成後に表示される画面で **JSON をダウンロード** し、そのファイルをこのフォルダの `credentials` フォルダに入れる
   （ファイル名は変えなくて大丈夫です）
6. 設定ファイル（1-3）を書いたあとに `python3 run.py check` を実行するとブラウザが開くので、スプレッドシートを編集できる Google アカウントでログインし、**許可** を押す
   （2回目以降はログイン不要です。許可情報は `credentials/token.json` に保存されます）

> `credentials` フォルダの中身は他人に渡さないでください。Git には保存されないようにしてあります。
>
> 組織のポリシーで許可されている場合は、サービスアカウントの鍵（JSON）を `credentials` フォルダに置いても使えます。
> その場合は、サービスアカウントのアドレスにスプレッドシートを「編集者」として共有してください。

### 1-3. 設定ファイルを書く

一度、次のコマンドを実行すると `config.toml` が作られます。

```bash
python3 run.py check
```

`config.toml` をテキストエディットなどで開き、「（要記入）」の部分を書き換えます。

| 項目 | 書く内容 |
|---|---|
| `spreadsheet_id` | スプレッドシートURLの `/d/` と `/edit` の間の文字列 |
| `[sender]` | 会社名・氏名・フリガナ・メールアドレス・電話・郵便番号・住所（署名とフォーム入力に使います） |
| `[sender] email` | **Mac の「メール」アプリに登録してある**送信用アドレス |

### 1-4. 文面を確認・修正する

- メールの文面：`templates/email.txt`
- フォームの文面：`templates/form.txt`

1行目が件名、`---` の下が本文です。`{店名}` のような `{ }` の部分は、会社ごとに自動で置き換わります。

| 差し込み | 入る内容 |
|---|---|
| `{店名}` | 確認後店名 |
| `{会社名}` | 公開運営主体（空なら店名） |
| `{宛先名}` | 「会社名（改行）店名」。会社名が空、または店名に含まれる場合は店名だけ |
| `{宛名}` | 「会社名＋店名 ご担当者様」 |
| `{送信者会社名}` `{送信者姓}` `{送信者氏名}` `{送信者電話}` など | config.toml の [sender] の内容 |
| `{都道府県}` `{重点エリア}` など | スプレッドシートの見出し名をそのまま書くと、その列の値が入ります |

特定電子メール法では、営業メールに送信者の住所と、受信を拒否できる旨・その連絡先を表示するよう定められています。文面を変えるときは注意してください。

## 2. 毎日の使い方

ターミナルでフォルダに移動し、準備した環境を有効にしてから使います。

```bash
cd ~/Desktop/-HP/sales-mailer
```

```bash
source .venv/bin/activate
```

### 送信対象の確認

```bash
python3 run.py check
```

メール・フォームそれぞれの送信対象の件数と、今日すでに送った件数が表示されます。

### 文面のプレビュー（送信しない）

```bash
python3 run.py preview -n 3
```

### 自分宛てにテスト送信（最初に必ず1回）

```bash
python3 run.py test-mail 自分のメールアドレス
```

初回は「"ターミナル"が"メール"を制御しようとしています」と表示されるので **OK** を押してください。

### メールを送信する

```bash
caffeinate -i python3 run.py mail
```

- 送信先の一覧が表示され、`y` を押すと送信が始まります
- 1通ごとに 60〜120 秒あけて、1日の上限（初期設定 50 通）まで送ります
- 途中で止めたいときは `Ctrl + C`。それまでに送った分は記録されています
- `caffeinate -i` は、送信中に Mac がスリープしないようにするためのものです
- 今回だけ件数を減らしたいときは `python3 run.py mail --limit 10`

### 都道府県ごとに分けて送る

`check`・`preview`・`mail`・`form` のどれにも `--pref` を付けると、その都道府県の会社だけを対象にできます。
「九州」「関東」などの地方名も使えます。

```bash
python3 run.py check --pref 宮崎
```

```bash
caffeinate -i python3 run.py mail --pref 宮崎 鹿児島
```

```bash
python3 run.py form --pref 九州
```

`python3 run.py check` を `--pref` なしで実行すると、都道府県ごとの送信対象の件数が表示されます。
1日の上限は、都道府県を分けて送っても合計で数えます。

### お問い合わせフォームを送信する（半自動）

```bash
python3 run.py form
```

ブラウザが開き、1社ずつフォームに自動入力されます。内容を確認して、**ブラウザで自分で送信ボタンを押し**、
ターミナルに戻って次のキーを押します。

| キー | 意味 |
|---|---|
| Enter | 送信した（記録して次の会社へ） |
| `s` | スキップ（今後この会社はフォーム対象にしない） |
| `n` | 営業お断りだった（今後送らない） |
| `r` | ブラウザで別のページを開いたので、もう一度自動入力する |
| `q` | 終了 |

- 「営業お断り」の記載があるページでは ⚠ が表示されます。その場合は送らずに `n` を押してください
- 選択肢（お問い合わせ種別など）・画像認証・自動で入らなかった欄は、ブラウザで直接入力してください
- 問い合わせページではなくトップページが開いた場合は、ブラウザで問い合わせページを開いてから `r` を押してください

## 3. スプレッドシートに記録される内容

- **92_送信ログ** タブ（自動で作成）：日時・方法・結果・リードID・店名・都道府県・宛先
- 送信した会社の行：**アプローチ回数** が1増え、**最終コンタクト** に「日付 メール」「日付 フォーム」と入ります

ログに「送信済み」「スキップ」「営業お断り」と記録された会社には、次回以降は送りません。
送り直したい場合は、送信ログからその行を削除してください（「エラー」の会社は次回もう一度送ります）。

## 4. 送らない会社のルール

**特定の会社を送らないようにするには**、`exclude.txt` に店名を1行に1社ずつ書いてください。
店名・会社名にその言葉が含まれる会社には、メールもフォームも送りません。
`python3 run.py check` で、どの会社が除外されたか（見つからなかった名前があるか）を確認できます。


`config.toml` の `[filter]` で変更できます。初期設定では次の会社には送りません。

- 「対象判定」が「除外」の会社（「対象」「要確認」には送ります）
- 「リスト状態」が sales-ready でない会社
- 「営業状態」に「閉店」「休業」「廃業」「移転」が入っている会社
- 「備考」に「配信停止」「送信不可」「営業お断り」「NG」が入っている会社
- （`skip_already_contacted = true` にした場合のみ）「アプローチ回数」「最終コンタクト」が入っている会社
- 04_全国拡張候補タブで「メール採用判定」が「送信候補」でない会社（メールのみ。フォームがあればフォーム対象）
- 同じメールアドレス・同じフォームには1回だけ
- グーバイク・バイクブロス・SNS などのポータルサイトのフォーム

**「配信停止」と返信が来たら**、その会社の「備考」に「配信停止」と書いてください。以後は送られません。

## 5. 送信数の上限について

迷惑メール扱いされたり、メールサーバーの送信制限に引っかかったりしないよう、初期設定は1日50通です。
問題なく届いているようであれば、`config.toml` の `[mail] daily_limit` を少しずつ増やしてください。
上限を大きく増やす前に、ご利用のメールサーバー（エックスサーバーなど）の送信数制限も確認してください。

## ファイル構成

```
run.py                     実行するファイル
exclude.txt                送らない会社のリスト
config.example.toml        設定の見本（初回に config.toml としてコピーされます）
config.toml                自分の設定（Git には保存されません）
credentials/               Google の鍵ファイルを置く場所（Git には保存されません）
templates/email.txt        メールの文面
templates/form.txt         フォームの文面
salesmailer/               プログラム本体
```
