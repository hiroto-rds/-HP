# Rデザインスタジオ 営業支援サイト

法人企業から営業支援・営業代行の相談を獲得するための、1ページ完結型（LP）のトップページです。
「Rデザインスタジオ 営業専門HP構成案」（2026年10月12日版）の構成・掲載文案をもとに制作しています。

## ファイル構成

```
index.html            トップページ（全セクション）
privacy.html          プライバシーポリシー
assets/css/style.css  デザイン（ネイビー×白×青緑、レスポンシブ対応）
assets/js/config.js   お問い合わせフォームの送信先設定 ← 公開時にここを編集
assets/js/main.js     メニュー・アニメーション・数字のカウントアップ・フォーム処理
contact.php           フォーム送信用のPHP（PHPが使えるサーバーで利用する場合）
assets/img/           プロフィール写真（WebP と JPEG、幅800px・1400px）
```

ビルド作業は不要です。ファイル一式をそのままサーバーにアップロードすれば公開できます。

## 掲載している数字と根拠

構成案に記載のある事実のみを掲載し、売上額・成約件数などは追加していません。
また、**具体的な取引先名・自治体名・委託先の社名は掲載しない方針**です（業種・自治体の種別のみ記載）。

| 掲載内容 | 構成案の記載 | 表記上の配慮 |
|---|---|---|
| 担当エリア年間売上 1,000万円以上 | 会社員時代の実績 | 「担当エリアにおける年間売上」と注記し、個人の新規創出額とは書いていない |
| 見積取得 計8社（第1回5社・第2回3社） | ギフト営業の実績 | 「見積取得」と明記し、「契約成立件数ではありません」と注記 |
| 町（自治体）でのアポイント獲得／町役場への訪問・同行 | 自治体アプローチ | 自治体名は伏せ、「契約」「受注」とは書いていない |
| レンタルバイク加盟店開拓営業 | 独立後の活動 | 委託先の社名は伏せ、件数・成果は記載していない |

営業実績セクションには「アポイント獲得 → 訪問・商談 → 見積取得 → 契約」の段階を示し、見積取得と契約成立を区別していることをサイト上でも明示しています。

## お問い合わせフォームの設定

**現在の設定：B（contact.php）／エックスサーバーで公開／受信先 `info@r-design-studio.jp`**

- `assets/js/config.js` … `formEndpoint: "contact.php"`
- `contact.php` … `MAIL_TO` と `MAIL_FROM` を `info@r-design-studio.jp` に設定（自動返信あり）

### エックスサーバーでの公開手順

1. **メールアドレスの確認**
   サーバーパネル →「メールアカウント設定」で `info@r-design-studio.jp` が作成済みか確認（なければ作成）
2. **PHPバージョンの確認**
   サーバーパネル →「PHP Ver.切替」で PHP 7.4 以上（推奨 8.x）になっているか確認
3. **アップロード**
   ファイルマネージャー または FTP で、ドメインの `public_html/` にファイル一式をアップロード
   - アップロードするもの：`index.html` `privacy.html` `contact.php` `assets/` フォルダ
   - `README.md` はアップロード不要
   - 既存サイトと同じドメインで別の場所に置く場合は、`public_html/sales/` のようにフォルダを作ってその中へ
4. **SSL の確認**
   サーバーパネル →「SSL設定」で独自SSLが有効になっているか確認（`https://` で表示されること）
5. **テスト送信**
   公開URLからフォームを送信し、次の2通が届くことを確認
   - `info@r-design-studio.jp` に「【営業支援サイト】○○ 様よりご相談」
   - フォームに入力したアドレスに「【Rデザインスタジオ】お問い合わせを受け付けました」
   - 届かない場合は迷惑メールフォルダも確認
6. **送信元ドメインの制限（推奨）**
   公開URLが決まったら、`contact.php` の `ALLOWED_ORIGINS` に設定
   ```php
   const ALLOWED_ORIGINS = ['https://r-design-studio.jp', 'https://www.r-design-studio.jp'];
   ```

> 同じ送信元からは60秒間連続送信できないため、テストを繰り返す場合は1分ほど空けてください。

以下は、他の公開先に移す場合などの参考情報です。

| | A. Formspree | B. contact.php（PHP） |
|---|---|---|
| 向いている公開先 | GitHub Pages / Netlify / Vercel など静的ホスティング | エックスサーバー、さくら、ロリポップなどPHPが使えるレンタルサーバー |
| サーバー側の準備 | 不要（外部サービスが受信） | 不要（同梱の contact.php を使用） |
| 費用 | 無料プランあり（月の送信数に上限） | サーバー代のみ |
| 自動返信メール | 有料プランで利用可（プラン内容は公式サイトでご確認ください） | あり（contact.php で設定） |

### A. Formspree を使う（サーバー不要・おすすめ）

1. https://formspree.io でアカウントを作成し、「New Form」でフォームを作る
   - 通知先メールアドレスに、問い合わせを受け取りたいアドレスを設定
2. 発行されたエンドポイント（`https://formspree.io/f/xxxxxxxx` の形式）をコピー
3. `assets/js/config.js` を編集

   ```js
   window.RDS_CONFIG = {
     formEndpoint: "https://formspree.io/f/xxxxxxxx",
     fallbackEmail: "info@your-domain.jp"   // 送信エラー時に案内するアドレス（任意）
   };
   ```

4. サイトを公開し、実際にテスト送信する
   - 初回送信時、Formspree から確認メールが届くので承認してください
   - プランによっては、管理画面で受け付けるドメインを公開URLに制限できます（他サイトからの悪用防止）

フォームからは次の項目が送られます：`company` `name` `email` `tel` `topics` `meeting`（打ち合わせ方法）`business` `message` `consent`。
件名（`_subject`）と返信先（`_replyto`）も自動で設定されるため、届いたメールにそのまま返信できます。

### B. PHP が動くレンタルサーバーで contact.php を使う

1. `contact.php` 冒頭の設定を書き換える

   ```php
   const MAIL_TO        = 'info@your-domain.jp';      // 問い合わせを受け取るアドレス
   const MAIL_FROM      = 'no-reply@your-domain.jp';  // 送信元（サイトと同じドメイン推奨）
   const MAIL_FROM_NAME = 'Rデザインスタジオ 営業支援サイト';
   const SEND_AUTO_REPLY = true;                       // 相談者への自動返信
   const ALLOWED_ORIGINS = ['https://your-domain.jp']; // 自サイトからの送信のみ受け付ける
   ```

   - `MAIL_FROM` はサイトと同じドメインのアドレスにしてください。他ドメイン（Gmail等）を使うと迷惑メール扱いになりやすくなります。
2. `assets/js/config.js` の `formEndpoint` を `"contact.php"` にする
3. ファイル一式をサーバーへアップロード（PHP 7.4 以上）
4. 実際にテスト送信し、受信と自動返信を確認する

contact.php には次の対策を入れています。

- 必須項目・メール形式・文字数のサーバー側チェック
- メールヘッダーへの改行混入（ヘッダーインジェクション）の防止
- スパムボット対策（人には見えない入力欄に入力があれば送信しない）
- 同じ送信元からの連続送信を60秒間制限
- 自動返信には自由記述欄を含めない（第三者への迷惑メールの踏み台にされるのを防ぐため）
- 文字化けしにくい UTF-8 で送信

> GitHub Pages など PHP が動かない場所では B は使えません。その場合は A を利用してください。

## 公開前に確認・差し替えが必要な項目

構成案「公開時の確認事項」「公開前に決める項目」に基づくチェックリストです。

- [ ] **数値の根拠確認**：担当期間・1,000万円の集計範囲、前職の守秘義務に抵触しないか
- [x] **取引先・自治体名**：具体名は掲載しない方針で対応済み
- [x] **よくある質問の回答**：対応エリア（オンラインは全国／対面は宮崎市内）を反映、契約期間の項目は削除済み
- [x] **プロフィール写真**：差し替え済み（`assets/img/profile-*.webp / .jpg`）
- [x] **プライバシーポリシー**：`privacy.html` を作成済み。フォームの同意欄とフッターからリンク
- [x] **プライバシーポリシー**：制定日 2026年10月12日。住所・代表者名は掲載せず「ご請求時に開示」とする方針
- [ ] **プライバシーポリシーの更新**：Googleアナリティクス等を導入する場合は「7. Cookie・外部サービスについて」を追記
- [ ] **フォーム送信先**：上記 A または B を設定し、テスト送信を確認
- [ ] **OGP画像・公開URL**：SNSで共有された際の画像（`og:image`）と `og:url` を設定

## ローカルでの確認方法

```bash
# 表示確認だけなら
npx serve .

# contact.php まで動かして確認する場合（メールは実際には送られません）
php -S 127.0.0.1:8000
```

ブラウザで http://127.0.0.1:8000 を開きます。
